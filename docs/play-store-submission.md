## D. 계정 생성과 삭제 ✅

**앱에서 지원하는 계정 생성 방법:**
- ✅ **소셜 로그인 또는 제3자 인증** — 카카오, Apple

근거: `src/app/index.tsx`의 `enterSocial('kakao'|'apple')`이 실제로 버튼에 연결돼
있고(로그인 화면 117·134행), `src/lib/auth.ts`가 카카오 SDK와 Apple 인증을 호출한다.
이메일/비밀번호 가입 화면은 존재하지 않는다.

이걸 체크하면 Google의 계정 삭제 요구사항이 켜지고 **둘 다** 있어야 한다.

| 요구사항 | 상태 | 근거 |
|---|---|---|
| 1. 앱 안에서 계정·데이터 삭제 | ✅ **있음** | 설정 → "계정 삭제" (`src/app/settings.tsx:190-199`), 2단계 확인 후 `deleteAccount()`가 7개 테이블(`favorites`, `likes`, `reviews`, `reservations`, `visit_counts`, `profiles`, `push_tokens`) 삭제 + 카카오 연결 해제 |
| 2. **웹에서 접근 가능한 삭제 요청 URL** | ✅ **있음** | `https://fifawithkupa.github.io/sitnow-legal/account-deletion` — HTTP 200 확인. 앱 이름·개발자명(DEVNU)·삭제 단계·삭제되는 데이터·보존 정책·문의처 포함 |

Play 데이터 보안의 삭제 URL 칸과 App Store Connect 양쪽에 위 주소를 넣는다.

> 참고: Apple 로그인 사용자의 **refresh token 폐기**가 아직 미구현이다
> (`src/lib/account.ts:73-76`). Apple이 요구하는 사항이라 iOS 심사에서 지적될 수 있다.

## G. 릴리즈

⚠️ **현재 프로덕션 AAB(versionCode 3)는 낡았다.** 그 이후 커밋에서
어댑티브 아이콘 전경 교체, 스플래시 변경, 로그인 세션 유지, Apple 콜백 라우트가
들어갔다. **제출용 프로덕션 빌드를 다시 만들어야 하고, versionCode는 4가 된다.**

| 항목 | 값 |
|---|---|
| App Bundle | 새 프로덕션 빌드 (`eas build -p android --profile production`) |
| versionCode | **4** (`appVersionSource: remote` + `autoIncrement: true`) |
| 출시명 | `1.0.0 (4)` |
| 국가/지역 | 대한민국 |
