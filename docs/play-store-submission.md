## 5. 코드 밖에서 반드시 해야 하는 일 🙋

Play Console 작성과 별개로, 이게 안 되면 **앱은 심사에 통과해도 실제로 동작하지 않는다.**

### 5-1. 카카오 키 해시 등록 (최우선)

AAB를 내부 테스트에 올린 뒤:
1. Play Console → 설정 → 앱 무결성 → **앱 서명** → SHA-1 인증서 지문 복사
2. base64 키 해시로 변환 (콜론 제거 후):
   ```
   echo "D966427BF1E1..." | xxd -r -p | openssl base64
   ```
3. Kakao Developers → 내 애플리케이션 → 플랫폼 → Android → 키 해시에 추가

EAS 업로드 키(`D9:66:42:7B:F1:E1:D6:A7:18:78:16:E6:E2:41:4?:3:0A:40:FE:9A:E0`)도
같이 등록해두면 직접 설치한 APK로도 로그인이 된다.

### 5-2. 네이버 지도 Android 패키지 등록

NCP 콘솔 → Maps → Application → Android 패키지명에 `com.sitnow.app` 추가.
안 하면 지도가 인증 실패로 빈 화면이 된다.

### 5-3. Apple 로그인(Android 웹 OAuth) 설정

Android에도 Apple 버튼이 노출되도록 병합했으므로(`ddaad21`), 아래가 없으면
버튼을 눌렀을 때 오류가 난다.
- Supabase → Authentication → URL Configuration → Redirect URLs에 `seatnowapp://**`
- Supabase → Providers → Apple 활성화 (Service ID + .p8 키)
- Apple Developer → Service ID를 `com.sitnow.app`에 연결, Return URL에 Supabase 콜백

> 이게 부담되면 Android 첫 출시에서는 Apple 버튼을 다시 숨기는 편이 낫다.
> 눌렀을 때 실패하는 버튼이 있으면 심사에서 지적당한다.
